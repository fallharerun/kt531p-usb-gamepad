# kt531p-usb-gamepad

MINI-Z 用プロポ KT-531P のステアリングとスロットルを、USB HID ゲームパッドの 2 軸として PC に入力する Seeed XIAO RP2040 用ファームウェア。  
手元では動作したが、プロポの製造時期などによって違いがあるかは不明。

## 特徴

- 2 軸出力 — X = ステアリング / Y = スロットル、16bit 符号付き、250Hz
- PC なしでキャリブレーション — ポテンショメータの個体差はデバイス側が保持するので、プロポが違っても同じバイナリで動く
- キャリブレーション値は EEPROM に保存 — 電源断でもファームウェアの再書き込みでも消えない
- フェイルセーフ — ポテンショメータの電源線・GND 線の断線と、ワイパーの短絡を検出して軸をニュートラルへ落とす

## 必要なもの

- KT-531P
- Seeed XIAO RP2040
- PlatformIO
